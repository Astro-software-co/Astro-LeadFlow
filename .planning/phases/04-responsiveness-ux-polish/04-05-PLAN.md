  <action>
Add a `@media (prefers-reduced-motion: reduce)` block inside the existing `@layer utilities` block in `frontend/src/index.css`. Insert it AFTER the `@keyframes slide-up` block (after line 186) but BEFORE the closing `}` of `@layer utilities` (line 187).

Add this CSS block:
```css

  @media (prefers-reduced-motion: reduce) {
    .animate-fade-in {
      animation: none;
    }

    .animate-slide-up {
      animation: none;
    }

    .animate-spin {
      animation-duration: 1.5s;
    }
  }
```

This:
- Fully disables `animate-fade-in` and `animate-slide-up` (elements appear instantly)
- Slows `animate-spin` (Loader2 spinners) to 1.5s instead of the default 1s — still communicates loading state but at a motion-safe speed
- Does NOT override `animate-pulse` (used by Skeleton) — Tailwind CSS v3's `animate-pulse` already respects prefers-reduced-motion per RESEARCH.md assumption A1
- Does NOT override shadcn/ui accordion animations — they are user-triggered micro-interactions below motion sensitivity threshold
