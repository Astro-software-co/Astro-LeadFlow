**KanbanColumn.tsx — Change column width (line 46):**

This replaces the fixed `w-[300px]` with `min-w-[260px]`. At 375px viewport with 16px padding on each side and a 16px gap, this shows approximately 1.4 columns (375 - 32 = 343px available; 260px first column + 16px gap + ~67px of second column visible).

**KanbanBoard.tsx — Add relative positioning and gradient overlay (line 175):**

Change the scroll container:
From:
```tsx
<div className="flex gap-4 overflow-x-auto pb-4">
  {columns.map((column) => (
```
To:
```tsx
<div className="relative">
  <div className="flex gap-4 overflow-x-auto pb-4">
    {columns.map((column) => (
```

Then add the gradient overlay and closing `</div>` after the scroll container's closing `</div>`. The full structure becomes:
```tsx
<div className="relative">
  <div className="flex gap-4 overflow-x-auto pb-4">
    {columns.map((column) => (
      <KanbanColumnComponent
        key={column.id}
        id={column.id}
        title={column.title}
        description={column.description}
        cards={getCardsByColumn(column.id)}
        onAssume={handleAssume}
        onAdvance={handleAdvance}
        onArchive={handleArchive}
        onCardClick={handleCardClick}
      />
    ))}
  </div>
  <div className="pointer-events-none absolute right-0 top-0 h-full w-8 bg-gradient-to-l from-background to-transparent md:hidden" />
</div>
```

Key details:
- The gradient overlay div uses `pointer-events-none` to avoid blocking drag or scroll events (per Pitfall 3 in RESEARCH.md).
- `md:hidden` ensures the gradient only appears below 768px.
- `from-background to-transparent` adapts to both light and dark mode via the CSS variable.
- The overlay is inside a `relative` wrapper (not the scroll container itself, which must remain the overflow parent).

**IMPORTANT:** The gradient overlay is a sibling of the scroll container inside the `relative` wrapper. It is NOT inside the overflow container — placing it inside would cause it to scroll away. It sits outside the scrollable area but inside the `relative` parent.
