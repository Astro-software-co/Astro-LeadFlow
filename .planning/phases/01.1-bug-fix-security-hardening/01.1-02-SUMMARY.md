# Phase 01.1 Plan 02: Auth UI Bugs + RBAC + CSP Summary

**One-liner:** Login-only form with no registration tab, landing CTAs fixed to mailto, RoleGate RBAC wrapper applied to /app/configuracoes, CSP meta tag in index.html.

## What Was Built

### Task 1: Remove public registration from Login page and fix landing CTAs (d8f0aea)

**Login.tsx** was simplified from a dual-tab login/registration page to a login-only form:
- Removed `isLogin` state variable and all conditional rendering
- Removed registration fields: `nome`, `telefone`, `confirmarSenha`
- Removed tab toggle buttons (Entrar/Cadastrar)
- Removed `register` import from `useAuth()`
- Simplified form state to `{ email, senha }` only
- Removed password confirmation validation
- Removed unused icon imports: `User`, `Phone`
- Submit button now always shows "Entrar" (no ternary)
- "Esqueceu a senha?" link kept

**CTASection.tsx** "Agendar demonstracao" button changed from `<Link to="/app/login">` to `<a href="mailto:contato@astrosoftware.com.br?subject=...">`. The primary "Comece gratis agora" CTA still routes to /app/login correctly.

**HeroSection.tsx** — unchanged, already uses `<a href="#contato">` which scrolls to CTASection (acceptable secondary CTA behavior per plan).

### Task 2: Create RoleGate component and apply to /app/configuracoes (989877c)

Created `frontend/src/components/layout/RoleGate.tsx`:
- Accepts `allowedRoles: string[]`, `children`, and optional `fallback` prop
- Reads `user.role` via `useAuth()` hook
- Renders `DefaultFallback` ("Acesso restrito" with ShieldAlert icon) when role not in allowedRoles
- Supports custom fallback via prop

Updated `frontend/src/App.tsx`:
- Imported `RoleGate` from `@/components/layout/RoleGate`
- Wrapped `/app/configuracoes` route with `<RoleGate allowedRoles={['ADMIN', 'MANAGER']}>`
- No other routes gated (per Decision [C]: minimal RBAC for v1)

### Task 3: Content-Security-Policy meta tag in index.html

CSP meta tag was already present in `frontend/index.html` from plan 01.1-01 (parallel execution). Verified the CSP contains all required directives:
- `default-src 'self'`
- `script-src 'self' 'unsafe-inline'` (Vite dev compatibility)
- `style-src 'self' 'unsafe-inline' https://fonts.googleapis.com`
- `font-src 'self' https://fonts.gstatic.com`
- `img-src 'self' data: blob:`
- `connect-src 'self' http://localhost:8080 https://api.astro.com.br`
- `frame-src 'none'` (clickjacking protection)
- `object-src 'none'`
- `base-uri 'self'`
