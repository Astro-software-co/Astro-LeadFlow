    **Per Decision [C]:** RBAC minimal — `/app/configuracoes` requires ADMIN or MANAGER. All other routes open to any authenticated role.

    **Create `frontend/src/components/layout/RoleGate.tsx`:**

    ```typescript
    import { useAuth } from '@/contexts/AuthContext';
    import { ShieldAlert } from 'lucide-react';

    interface RoleGateProps {
      allowedRoles: string[];
      children: React.ReactNode;
      fallback?: React.ReactNode;
    }

    function DefaultFallback() {
      return (
        <div className="flex min-h-[50vh] flex-col items-center justify-center gap-4 text-center">
          <div className="flex h-16 w-16 items-center justify-center rounded-full bg-destructive/10">
            <ShieldAlert className="h-8 w-8 text-destructive" />
          </div>
          <div>
            <h2 className="text-xl font-semibold text-foreground">Acesso restrito</h2>
            <p className="mt-1 text-sm text-muted-foreground">
              Voce nao tem permissao para acessar esta pagina.
            </p>
          </div>
        </div>
      );
    }

    export function RoleGate({ allowedRoles, children, fallback }: RoleGateProps) {
      const { user } = useAuth();

      if (!user || !allowedRoles.includes(user.role)) {
        return fallback ?? <DefaultFallback />;
      }

      return <>{children}</>;
    }
    ```

  <action>
    **SEC-005: Add a baseline Content-Security-Policy as a `<meta>` tag in `index.html`.**

    Add the following `<meta>` tag inside `<head>`, after the existing meta tags:

    ```html
    <meta http-equiv="Content-Security-Policy" content="
      default-src 'self';
      script-src 'self';
      style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
      font-src 'self' https://fonts.gstatic.com;
      img-src 'self' data: blob:;
      connect-src 'self' http://localhost:8080 https://api.astro.com.br;
      frame-src 'none';
      object-src 'none';
      base-uri 'self';
    " />
    ```

    Key decisions in this CSP:
    - `script-src 'self'` — no inline scripts (Vite handles this via module bundling). Note: Vite dev server injects inline scripts, so this CSP may need `'unsafe-inline'` in dev. To handle this, add a comment: `<!-- Note: Vite dev server may require 'unsafe-inline' for script-src during development. This CSP is for production. -->`
    - `style-src 'unsafe-inline'` — required because Tailwind and shadcn/ui inject inline styles
    - `font-src` allows Google Fonts CDN
    - `connect-src` allows localhost:8080 (dev backend) and production API domain
    - `frame-src 'none'` and `object-src 'none'` — clickjacking protection
    - `img-src` allows data URIs (for inline SVGs) and blob (for image previews)

    **Important:** For the CSP to work in Vite dev mode, the `script-src` may need adjustment. Add the CSP with a development note. In production builds, Vite does NOT inject inline scripts so `script-src 'self'` is fine.

    For dev compatibility, use this version:
    ```html
    <meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: blob:; connect-src 'self' http://localhost:8080 https://api.astro.com.br; frame-src 'none'; object-src 'none'; base-uri 'self';" />
    ```

    The `'unsafe-inline'` for scripts is a trade-off for dev compatibility. A stricter CSP with nonces should be configured at the server level in production (not in a meta tag).
